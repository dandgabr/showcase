# Avisos de terceiros

## Coacus

O showcase apresenta e consulta em tempo de execução o catálogo público de [dandgabr/Coacus](https://github.com/dandgabr/Coacus), sem manter uma cópia local. Na revisão de 21/10/2026, o arquivo [LICENSE do Coacus](https://github.com/dandgabr/Coacus/blob/main/LICENSE) era a GNU Affero General Public License, versão 3 (AGPL-3.0); este repositório mantém cópia byte a byte desse texto. O catálogo remoto continua hospedado e licenciado pelo Coacus; consulte a licença e os avisos na origem para o conteúdo upstream.

## Dependências de execução

O site não carrega bibliotecas JavaScript, folhas de estilo, fontes ou imagens hospedadas por terceiros em tempo de execução. O artefato é composto por HTML, CSS, módulos nativos do navegador e uma ilustração SVG deste repositório.

## Ferramentas de desenvolvimento e CI

Os testes usam Node.js e Python padrão. O workflow usa GitHub Actions oficiais referenciadas por SHA completo; suas licenças e termos pertencem aos respectivos projetos. Essas ferramentas não fazem parte do bundle entregue ao visitante.
