# Contribuindo

1. Crie uma branch e abra um pull request para `main`.
2. Explique o comportamento alterado e inclua evidência visual quando modificar a interface.
3. Execute as verificações descritas no README.
4. Não inclua arquivos gerados, credenciais, dados privados ou artefatos de browser.
5. Preserve acessibilidade, navegação por teclado, responsividade e `prefers-reduced-motion`.

O workflow de pull request valida o código sem publicar o site. A publicação é feita após merge em `main`.
